## Environment & Installation

The project is built using React 17 and Vite, requiring specific Node.js and npm versions for compatibility with the build toolchain [README.md#18-19](https://github.com/thetide557/ln-server-pub/blob/629bd918/README.md?plain=1#L18-L19). Note: `package.json` does not declare an `engines` field — the Node/npm version requirement is only documented in `README.md`.

### Prerequisites

- Node.js: `v16.x` (specifically tested up to `v16.15.0`) [README.md#18](https://github.com/thetide557/ln-server-pub/blob/629bd918/README.md?plain=1#L18-L18)

The `package.json` defines several scripts for different development modes and production optimization.

| Script | Command | Purpose |
| --- | --- | --- |
| `dev` | `vite --port 8765 --host` | Standard local development server on port 8765 [package.json#5](https://github.com/thetide557/ln-server-pub/blob/629bd918/package.json#L5-L5) |
| `dev:advanced` | `vite --port 8765 --host --mode advanced` | Development server with "advanced" feature flags enabled [package.json#6](https://github.com/thetide557/ln-server-pub/blob/629bd918/package.json#L6-L6) |
| `build` | `tsc && cross-env NODE_OPTIONS=--max-old-space-size=8192 vite build` | Production build with TypeScript checking and increased memory limit for Rollup [package.json#7](https://github.com/thetide557/ln-server-pub/blob/629bd918/package.json#L7-L7) |
| `build:advanced` | `node comb_feats ${npm_config_custom_options} && tsc && cross-env NODE_OPTIONS=--max-old-space-size=8192 vite build --mode advanced` | Production build for the "advanced"/plus variant. Runs `comb_feats.js` first, which writes `VITE_IS_<feat>=true` flags to `.env.advanced` based on the `--custom_options` npm config, then builds with `--mode advanced` [package.json#8](https://github.com/thetide557/ln-server-pub/blob/629bd918/package.json#L8-L8) |
| `serve` | `vite preview` | Locally preview the production build [package.json#9](https://github.com/thetide557/ln-server-pub/blob/629bd918/package.json#L9-L9) |

## Vite Configuration

The configuration in `vite.config.ts` handles asset aliasing, CSS pre-processing (Less), and complex proxying to backend services.

### Path Alias

`vite.config.ts` defines a `resolve.alias` mapping `@` to `/src`, enabling absolute imports such as `@/pages/...` and `@/components/...` throughout the codebase [vite.config.ts#76-83](https://github.com/thetide557/ln-server-pub/blob/629bd918/vite.config.ts#L76-L83)

### Development Proxy

The development server uses `vite`'s proxy to route API requests to the backend server defined by `baseUrl` (default: `http://172.16.20.11:17000/`) [vite.config.ts#61](https://github.com/thetide557/ln-server-pub/blob/629bd918/vite.config.ts#L61-L61)

## Deployment Configuration

For production, the application is deployed behind an Nginx server. The frontend must be configured to handle Single Page Application (SPA) routing and proxy API requests to the backend.

### Nginx Configuration Example

The following configuration ensures that the `pub` folder is served correctly and that browser refreshes on deep routes (e.g., `/xh/assetmgt`) are redirected to `index.html` via `try_files`[README.md#54-57](https://github.com/thetide557/ln-server-pub/blob/629bd918/README.md?plain=1#L54-L57)

```
server {
    listen       8765;
    server_name  _;
 
    root   /path/to/ln-server-pub/pub;
 
    location / {
        try_files $uri /index.html;
    }
 
    location /api/ {
        proxy_pass http://n9e.api.server; # Backend API address
    }
}
```

## Theming & Styling

The project uses `Less` for styling, with global variables injected during the build process via `vite.config.ts`. The primary theme color is `#0A4B9D`[vite.config.ts#173](https://github.com/thetide557/ln-server-pub/blob/629bd918/vite.config.ts#L173-L173)

Key configuration points:

- Global Variables: Injected from `/src/global.variable.less`[vite.config.ts#170](https://github.com/thetide557/ln-server-pub/blob/629bd918/vite.config.ts#L170-L170)
- Ant Design Overrides: Customizations for `primary-color`, `font-size-base` (12px), and table styles are applied directly in the Vite config `modifyVars` block [vite.config.ts#172-195](https://github.com/thetide557/ln-server-pub/blob/629bd918/vite.config.ts#L172-L195)
- Icons: Uses a custom `IconFont` component for platform-specific iconography [src/components/menu/topMenuXH.tsx#9](https://github.com/thetide557/ln-server-pub/blob/629bd918/src/components/menu/topMenuXH.tsx#L9-L9)
